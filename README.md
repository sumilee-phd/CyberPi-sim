# CyberPi 3D 기기 탐색 · 편집 가능한 소스

작성일: 2026-11-24 · 기울기 게임 LCD 모의 실행 추가: 2026-11-24

**온라인 실행: <https://sumilee-phd.github.io/CyberPi-sim/>** (IoT시스템이해와 구축 수업용 시뮬레이터)

CyberPi를 회전·확대하고, 부품별 설명과 A·B 버튼의 LED 제어 예제를 살펴보는 Three.js 페이지입니다. 「기울기 게임」 메뉴에서는 2주차 실습 4 「SPACE DODGE」 예제 코드의 실행 화면을 128×128 LCD 모의 화면으로 보여줍니다. **공개 도면·공식 부품 사진·판매 모델의 공개 분해 미리보기를 대조해 직접 제작한 상세 재구성 모델**을 사용합니다. 공식 CAD 원본, 구매한 상용 모델, 영상에서 추출한 3D 데이터는 사용하지 않았습니다.

## 바로 실행

온라인에서는 위 주소를 Chrome·Edge 등 WebGL 지원 브라우저로 엽니다. 인터넷이 없는 PC에서는 아래 방법으로 실행합니다.

1. `실행.bat`를 실행합니다. Node.js가 설치된 현재 PC에서 동작합니다.
2. 브라우저에서 <http://127.0.0.1:8791> 을 엽니다.
3. 종료하려면 서버 창에서 `Ctrl+C`를 누릅니다.

또는 이 폴더에서 `npm start`를 실행합니다. `dist/`에 필요한 Three.js 파일을 포함했으므로 페이지 실행에 npm 설치나 외부 CDN 접속은 필요하지 않습니다. HTML을 더블클릭하면 브라우저의 로컬 파일 보안 때문에 모델을 불러오지 못할 수 있으므로 HTTP 서버로 실행합니다.

Python만 있는 PC에서는 `python -m http.server 8791 --bind 127.0.0.1 --directory dist`로 실행할 수도 있습니다. WebGL을 지원하는 브라우저가 필요합니다.

## 사용할 파일

| 파일 | 용도 |
|---|---|
| `models/CyberPi_educational.blend` | Blender에서 부품·재질·카메라를 수정하는 작업 원본 (로컬 전용) |
| `dist/assets/cyberpi-educational.glb` | Three.js나 다른 3D 뷰어에서 불러올 수 있는 모델 |
| `tools/build_model.py` | 모델을 다시 생성하는 Blender Python 소스 |
| `dist/index.html`, `dist/style.css` | 페이지 구성과 디자인 |
| `dist/app.js` | 카메라, 부품 선택, LED 시각화, 사용법 시연, 기울기 게임 화면 연결 코드 |
| `dist/lcd-game.js` | SPACE DODGE 예제 코드 원문과 LCD 모의 실행기(스프라이트·콘솔 출력·효과음·코드 줄 추적) |
| `dist/assets/sources.json`, `SOURCES.md` | 출처, 검색 결과, 확보 여부와 사용 범위 |
| `tools/build_standalone.mjs` | `dist/`를 HTML 파일 하나(`CyberPi_3D_실행.html`)로 묶는 스크립트 |
| `qa/model-render.png` | 모델 렌더 미리보기 (로컬 전용) |
| `qa/model-exploded.png` | 상부 케이스·기판·하부 케이스의 분해 렌더 (로컬 전용) |
| `qa/model-metadata.json` | 모델 구성·치수 검증 기록 (로컬 전용) |

공개 저장소(`sumilee-phd/CyberPi-sim`)에는 `dist/`, `tools/`, 문서와 실행 파일만 올립니다. `source/`(제조사·판매 모델 참조 이미지), `models/`, `qa/`, 오프라인 단일 HTML과 ZIP은 로컬에만 보관합니다. `main` 브랜치의 `dist/`가 바뀌면 GitHub Actions가 Pages로 배포합니다.

## 페이지에서 할 수 있는 일

- 드래그 회전, 휠·핀치 확대, 정면 보기, 자동 회전
- 부품 이름을 선택해 위치와 기능 확인
- 화면의 A·B 버튼 또는 실제 3D 버튼을 눌러 LED 켜기·끄기 확인
- 20초 사용법 시연을 재생·일시정지하고 슬라이더로 장면 이동
- 설명을 위한 부품 간격 펼치기
- 현재 3D 화면을 PNG로 저장하고 GLB 모델 다운로드

- 「기울기 게임」 메뉴에서 SPACE DODGE 예제를 LCD 모의 화면·3D 모델 화면에 실행하고, 실행 중인 코드 줄과 변수 값 확인

시연 내용은 Makeblock의 **프로그램 업로드 후 A=LED 켜기, B=LED 끄기** 예제에 기반합니다. 기기의 고정된 기본 동작이라는 뜻이 아닙니다. 실제 CyberPi 연결, 센서값 수집, 코드 업로드, 펌웨어 실행은 구현하지 않았습니다.

## 기울기 게임 (2주차 실습 4 · SPACE DODGE)

- 조작: 「프로그램 실행」 → LCD의 `A: 시작` 안내에 따라 A 버튼(화면 버튼, `A` 키, 스페이스, 3D 모델의 A 버튼). 기울기는 슬라이더(−90°~90°) 또는 ←·→ 키. 키를 떼면 0°로 돌아옵니다.
- 화면: 왼쪽은 128×128 LCD 모의 화면, 오른쪽은 기울기에 따라 움직이는 3D 기기와 같은 화면. 오른쪽 패널에는 예제 코드 원문, 실행 중인 줄(노란색)과 구간(파란색), `angle`·`speed`·`x`·`rock y`·`score` 값이 나타납니다.
- 동작 근거: 예제 코드의 흐름을 JavaScript로 그대로 옮겼습니다(`int(angle / 5)`의 0 방향 버림, 최대 속도 6, 벽 8~120, 운석 낙하 4, `DELAY` 0.05초, 5점마다 `level-up`).
- 확인한 사실: `draw_pixel("rocket")`·`draw_pixel("fire")`처럼 내장 아이콘 이름을 넣는 사용법은 실제 기기용 공개 예제 코드에서 확인했습니다. 효과음 이름 `ready`·`start`·`explosion`·`score`·`level-up`·`sad`는 제조사 Python API 문서 목록에 있습니다.
- 근사 표현: 아이콘 그림(16×16 직접 제작), 효과음(브라우저 합성음), 콘솔 글꼴 크기, 반복 속도(화면 갱신 시간 미반영)는 실제 기기와 다릅니다. 좌표 원점(왼쪽 위)·중심 기준 위치·`move_y` 방향은 예제 코드의 의도에 맞춘 가정이고, `is_touch`는 두 아이콘의 채워진 픽셀이 겹치면 닿은 것으로 판정합니다. `get_roll()`은 오른쪽으로 기울일 때 양수로 가정했으며 실제 방향이 반대라면 예제의 `DIR = -1`로 바꿉니다. 이 항목들은 제조사 공식 문서에서 확인하지 못했습니다.

## 제작 범위와 한계

- 도면의 외형 치수 84×35×12.88 mm(공식 사양표는 높이를 13 mm로 반올림)와 부품 안내를 참고했습니다. 버튼·커넥터 세부 치수, 곡면, 내부 기판은 공개 이미지에 따라 재구성한 형상입니다. 실측하거나 상용 CAD와 수치 비교한 결과가 아니므로 케이스 제작·가공·회로 설계의 기준으로 사용하지 않습니다.
- 상부·하부 케이스, 내부 리브·보스, PCB 소자·접점, LCD 프레임과 FPC, USB-C, 전면 LED 확산창을 보강했습니다. 공개 판매 썸네일은 재질·투명도가 누락되어 흰색으로 보이므로, 케이스 재질은 공식 실물 안내의 짙은 반투명 표현을 따랐습니다.
- 장면에서 펼치는 부품 간격은 설명용 연출입니다. 실제 분해 순서나 정밀 조립 관계를 검증한 자료가 아닙니다.
- 화면 문구·버튼 움직임·LED 색상·카메라 이동은 이 프로젝트에서 추가한 교육용 표현입니다. 실물과의 동작 비교 시험은 하지 않았습니다.
- 완성된 MP4와 내레이션은 포함하지 않습니다. 현재 파일은 후속 사용법 영상 제작에 사용할 편집 소스와 브라우저 시연입니다.
- 공식 CAD 배포 링크는 404 또는 로그인이 필요했고, 웹아카이브 STEP도 잘려 있어 사용하지 않았습니다. 실제 상세 3D 뷰어와 제작자 유료 원본 구매처는 `SOURCES.md`에 기록했습니다.

## 수정 방법

Blender에서 `.blend`를 열어 부품과 재질을 수정한 뒤 glTF Binary(`.glb`)로 내보내 `dist/assets/cyberpi-educational.glb`를 교체합니다. 공식·구매 모델로 교체할 때에는 아래 부품 이름을 맞추거나 `dist/app.js`의 부품 매핑을 수정해야 합니다.

주요 노드: `button_a_cap`, `button_b_cap`, `joystick_cap`, `screen_surface`, `led_1`부터 `led_5`, `usb_port`, `home_button`, `light_sensor`, `microphone`, `speaker`, `shell_top`, `shell_bottom`, `pcb`.

페이지는 모델의 전체 폭을 표시용 8.4 단위로 정규화합니다. 실제 GLB의 치수와 웹 화면의 좌표를 혼동하지 마세요. 버튼 이동 거리는 설명을 위해 과장했습니다.

`dist/app.js`의 `parts` 배열에서 부품 설명을, `steps` 배열에서 시연 자막과 카메라 구도를 수정할 수 있습니다. 시연은 MP4 파일이 아니라 재생 가능한 JavaScript 타임라인입니다.

예제 코드를 바꿀 때에는 `dist/lcd-game.js`의 `SPACE_DODGE_SOURCE`(화면에 보이는 원문)와 `program()`(실제 동작)을 함께 고칩니다. 코드 줄 강조는 `at('문구')`로 원문에서 줄을 찾으므로, 문구가 사라지면 페이지를 열 때 오류로 알려 줍니다. `npm run check`가 이 검사도 함께 실행합니다.

오프라인 단일 HTML은 `node --experimental-vm-modules tools/build_standalone.mjs [출력파일.html]`로 다시 만듭니다. 같은 이름의 파일이 있으면 덮어쓰지 않으므로, 이전 판을 `이전판/`으로 옮긴 뒤 실행합니다.

- Three.js 0.180.0: MIT, 원문 `dist/vendor/LICENSE` 포함.
- 제조사 제품명과 외형 참조 출처는 Makeblock입니다. 이 페이지는 제조사 공식 시뮬레이터가 아닙니다.
- `source/official-components.png`는 모델 대조용으로 내려받은 제조사 부품 안내 이미지입니다. 로컬 `source/`에만 보관하며 페이지에 재배포하지 않습니다.

- 제조사 CAD 및 Sitetechno.fr의 3D 데이터는 포함하지 않았습니다. 해당 자료의 라이선스를 이 재구성 모델에 그대로 적용한다고 주장하지 않습니다.

공개 게시 전에는 참조 이미지·제작자 모델 등 추가로 포함하는 외부 자료의 사용 범위를 확인하세요. 공개 저장소에는 위 참조 이미지를 넣지 않았습니다.
